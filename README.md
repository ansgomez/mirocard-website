# mirocard-website

One-page project website for the MiroCard, a batteryless, light-powered BLE smart card,
served with GitHub Pages at https://ansgomez.github.io/mirocard-website/.

Static HTML based on the Bootstrap 4.5 carousel example (Bootstrap, jQuery and Popper.js
under their own MIT licenses in `assets/`). Open `index.html` locally to preview.

See [mirocard-hardware](https://github.com/ansgomez/mirocard-hardware) for the full list of
MiroCard repositories.
